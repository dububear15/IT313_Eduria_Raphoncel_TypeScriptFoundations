# IT313 TypeScript Foundations

## Enrollment Eligibility Checker

This project is a TypeScript Enrollment Eligibility Checker.

The program calculates the average grade of each enrollee and determines whether the enrollee is PASSING or on PROBATION.

## TypeScript Features Used

- Basic TypeScript types
- Interfaces
- Union types
- Enums
- Optional properties
- Generics
- Promises
- Async/await
- Type narrowing
- Array map()
- Array reduce()
- Template literals
- Strict type checking

## Project Files

### main.ts

Contains the main program, enrollee data, eligibility reports, asynchronous data retrieval, generic grouping, and formatted output.

### gradeUtils.ts

Contains the EnrollmentStatus enum, computeAverage() function, and getStatus() function.

### tsconfig.json

Contains the TypeScript compiler configuration, including strict type checking.
